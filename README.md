# Welcome to Documentation 101

## We can make really simple formatting to arrange all necessary info!

### Between headers and lists we can make everything easier to read.

#### I want to show these few things
- How to add a code block
- How to add in line code
- How to make a table
- Hotkeys to view Markdown files


### Here's how you do those few things:

#### 1. To add a code block use three backticks \`\`\`
```python
for x in range(1,11):
    print(x)
```
#### 2. To add inline code sample use a single backtick \`
This way you can show your code, like a list comprehension
`my_list = [x**2 for x in range(1,11)]`, right here in your paragraph.

#### 3. Here's a table of key symbols to memorize

| Formatting | ---- | Markdown |
| ------- | ---- | ------- |
| Header | ---- | `# Header` |
| Subheader | ---- | `## Header` |
| Bold | ---- | `**bold**` |
| Italic | ---- | `*italic*` |
| Link | ---- | `[text](url)` |
| Bullet | ---- | `- item` |
| Number | ---- | `1. item` |
| Quote | ---- | `> quote` |
| Inline Code | ---- | text  \`code\`  more text |
| Code Block | ---- |	\`\`\` |
| Horizontal line | ---- | `---` |
| Strikethrough | ---- | `~~text~~` |

#### 4. Hotkeys for viewing:

#### Windows
---
View formatted file: Ctrl + Shift + V

View file preview: Ctrl + K, then V

#### Mac
---
View formatted file: Cmd + Shift + V

View file preview: Cmd + K, then V
